是申請季最可怕的事。

清大要自傳 4 頁內，交大要手寫 1000 字，有的學校要英文版，有的要學生證影本—— 每間學校的項目、格式、字數、截止日都不一樣。用 Google Sheets 打勾，三天後那張表就崩了。

這個系統把這件事變成一個儀表板。

常見問題

我的資料會被上傳嗎？

不會。系統只在你自己的電腦上執行，連線範圍僅限本機與同一個 Wi-Fi 的手機。你可以打開程式原始碼自己確認。

需要付月費嗎？

不用。一次購買，永久使用。

Windows 可以用嗎？

可以。核心程式是純 Python 標準庫，Windows 同樣能執行，包內附完整指令說明。

需要安裝什麼嗎？

只需要電腦內建的 Python 3，不需要安裝任何套件。macOS 直接可用。

上傳檔案有大小限制嗎？

單檔上限 64 MB。

我只有申請一間學校，值得嗎？

如果只申請一間、項目少於五項，直接用表格打勾就好。這個系統是為「三間以上、項目加起來超過 20 項」的人設計的。

可以退費嗎？

數位商品一經下載即無法收回，不提供退費。建議先用免費版確認符合需求。
